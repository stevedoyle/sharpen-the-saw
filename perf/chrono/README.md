# chrono

This is a simple CMake-based C++ project that measures the overhead of using std::chrono for timing a loop.

## Build Instructions

1. Create a build directory:
   ```bash
   mkdir -p build && cd build
   ```
2. Run CMake and build:
   ```bash
   cmake ..
   make
   ```
3. Run the executable:
   ```bash
   ./chrono
   ```
